# Doobies Gist

 ---
 
## Gameplay

- **Turn-based combat:** neem om de beurt strategische acties tegen je tegenstander.  
- **Doobie management:** kies locaties, upgrade je Doobies.
- **Unieke speelstijlen:** elke Doobie heeft een drastisch andere manier van vechten en spelen, waardoor elk gevecht verrassend en dynamisch is.  

---

## Platform

- **PC**  
- Besturing via **muis en toetsenbord**.  

---

## Features

- Casual roguelike 1v1 combat  
- Strategische locatiekeuze en upgrades  
- Verschillende Doobies met unieke speelstijlen  
- Snel uitbreidbare game-architectuur
